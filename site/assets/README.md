# Earth texture

`earth.jpg` is a recompressed copy of the 2048 × 1024 Earth atmosphere texture distributed with the three.js examples:
https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg

Source repository: https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets
Three.js is distributed under the MIT license; see `THREE-LICENSE.txt` alongside this file.

The texture is bundled locally. No third-party request is needed to render the globe.
